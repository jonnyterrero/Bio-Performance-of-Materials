# Graphene Oxide Biocompatibility Presentation

Vite + React slide deck and PowerPoint export for the FGCU BME3101C Graphene Oxide biocompatibility article. Companion to the [Bioperformance dashboard](../dashboard.html).

## Run locally

```bash
cd bioperformance-of-materials/graphene-oxide-presentation
npm install
npm run dev
```

Open the URL Vite prints (typically `http://localhost:3000`).

## Export

Use the in-app PowerPoint export control. A Gemini API key in `.env` (see `.env.example`) is only needed for AI-assisted features.
